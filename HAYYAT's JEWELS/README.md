# HAYYAT's JEWELS

A lightweight, frontend-only luxury jewellery experience built with plain HTML, CSS, and Vanilla JavaScript.

## Run locally

Open `index.html` with VS Code Live Server. No package installation, build step, backend, database, or Shopify account is required.

## Edit business details

Update `WHATSAPP_NUMBER` and the `CONTACT` object in `js/whatsapp.js`. Product, journal, review, and gallery content is centralized in the corresponding files under `js/`.

## Main journeys

Browse the collection, open a product, select options, add it to the bag, review the order, and open a pre-filled WhatsApp inquiry. Wishlist and bag data persist in the browser using localStorage.

## Note

This is a fictional brand demo. Reviews are explicitly sample/demo content and contact information is placeholder content intended for editing.
